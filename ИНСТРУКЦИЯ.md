# Yandex Disk Rescue — завершение этапа разработки исходников

**Один аккаунт Яндекс Диска.** Программа предназначена для локального спасения пользовательских файлов, в особенности фотографий и видео из «безлимита».

## Основная операция

1. На Windows 10/11 запустить полную сборку приложения.
2. Подключить Яндекс Диск по OAuth-токену Полигона.
3. Разрешить защищённое хранение токена DPAPI, если требуется скачивание без открытого окна.
4. Указать папку назначения и при необходимости включить автозапуск worker после входа в Windows.
5. Открыть отдельный Chrome кнопкой приложения и войти в тот же Яндекс ID.
6. Нажать **«Спасти фото: полный мастер»**. Программа проверяет квоту, идентичность аккаунта и полноту списка. С явного согласия пользователя создаёт папку «Безлимит» (если отсутствует) и перемещает фотографии в неё.
7. Скачивание и полная проверка содержимого запускаются через очередь. В конце появляется HTML-отчёт и CSV по каждой фотографии.
8. После завершения закрыть отдельный Chrome, удалить его профиль и сохранённый токен, а затем отозвать OAuth-токен в Яндексе.

## Важно

* **Перемещение в облаке не является скачиванием.** Фотография считается спасённой лишь после полной локальной проверки.
* Фото из безлимита начинают занимать обычную квоту после переноса. Изменение выполняется после подтверждения.
* Программа не удаляет оригиналы и не выполняет `rclone sync`; защита `--immutable` запрещает перезаписывать изменившиеся локальные копии.
* Ошибки Яндекса и неполные данные показываются отдельно. «Все файлы спасены» не отображается при неполном манифесте.
* Защищённая браузерная сессия всё равно может быть доступна другим вредоносным программам, работающим под текущим пользователем.
* **Это исходный код, не прошедший компиляцию и Windows-приёмку.** Не используйте экспериментальную сборку как единственную копию фотографий.

## Подготовка полного пользовательского пакета

`build-windows.ps1` запускается только на машине сборки под Windows с .NET 8 SDK, Node.js/npm и официальным `rclone.exe`. Он создаёт Portable ZIP и, при наличии Inno Setup 6, установщик. Внутрь сборки включаются rclone, Node и Playwright, поэтому конечному пользователю их вручную устанавливать не нужно.

Дальше необходимы: Windows-компиляция, тестовая учётная запись, проверка частичных ошибок, отключения USB-диска, проверка сетевого трафика и подписание готового установщика.
