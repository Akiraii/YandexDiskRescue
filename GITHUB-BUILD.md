# Получение EXE для Windows 10/11 (x64)

Этот каталог содержит **исходники и автоматическую сборку**, а не уже скомпилированное приложение.

## Без собственной Windows-машины для сборки

1. Загрузите файлы каталога в **свой** репозиторий GitHub, предпочтительно приватный. Не загружайте OAuth-токены, cookie или реальные фотографии.
2. В репозитории откройте **Actions → Yandex Disk Rescue - Windows executable → Run workflow**.
3. После загрузки файлов в ветку `main` либо `master` сборка запускается автоматически. Её можно также запустить вручную. При успешном завершении откройте запуск, раздел **Artifacts** и скачайте `YandexDiskRescue-Windows-x64`.
4. Внутри будут `YandexDiskRescue-Portable.zip`, `YandexDiskRescue-Setup.exe` и перечень SHA256. Проверяйте точное имя файлов и журнал сборки.
5. **Начинайте с тестового аккаунта и небольшого набора неважных файлов.** Текущий код использует неофициальный внутренний API Яндекса и не прошёл проверку на реальном аккаунте.

## Сборка на собственной Windows-машине

На Windows 10/11 x64 установите .NET 8 SDK, Node.js 22 (включая npm), Inno Setup 6 и официальный `rclone.exe` в `tools/`, либо в `PATH`. В директории проекта запустите `build-windows.ps1`. Он создаст те же EXE/ZIP в `dist/`.

## Что именно делает Actions

- Использует Windows runner и .NET 8.
- Скачивает rclone 1.75.2 из официального репозитория и проверяет SHA256 ZIP (`8A9DB2...AFF818`).
- Устанавливает фиксированную версию `playwright-core` 1.63.0 без postinstall-скриптов.
- Собирает два self-contained .NET EXE и комплект Node/rclone/JS.
- Создаёт Portable ZIP, Inno Setup EXE, перечень хешей.
- **Не содержит шагов загрузки или синхронизации личных данных.** В workflow нет OAuth-токенов пользователя.

## Важные ограничения

- Даже успешная компиляция не доказывает работоспособность неофициального API Яндекса.
- Установщик пока не подписан цифровым сертификатом; Windows SmartScreen может показать предупреждение. Не обходите предупреждения для непроверенных файлов без анализа источника.
- Google Chrome нужен на ПК пользователя для работы с безлимитными фотографиями; ни фото, ни cookie не входят в выпуск.
- Полный аудит сетевых подключений и тестирование реального сценария спасения не выполнялись.
